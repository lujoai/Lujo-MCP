AI Debug MCP — 静默失败检测（Silent Failure Detection）

接口返回 200，无异常日志，但实际数据不符合规范。系统自动识别这类"看起来成功但实际失败"的问题。

1. 实际请求结果（Actual）

POST /api/users — 响应
{
  "status_code": 200,
  "body": {
    "data": null,
    "message": "success"
  }
}
HTTP 200 OK 表面成功，无异常
↓ AI Debug MCP 自动比对规范

2. 期望规范（Spec）

期望：data 字段应为非空对象
{
  "kind": "api",
  "target": "/api/users",
  "expect": {
    "status": 200,
    "body_rules": {
      "data": { "name": "expected" }
    }
  }
}
↓ verify 引擎断言结果

3. 检测结果（VerifyResult）

matched: false   silent_failure: true 
{
  "matched": false,
  "diffs": [
    {
      "field": "body.data",
      "expected": { "name": "expected" },
      "actual": null
    }
  ],
  "silent_failure": true
}
⚠ 静默失败 detected
status_code=200（非 4xx/5xx），无异常，但 body.data 不符合规范 → 自动判定为静默失败

调用方式

POST /api/debug/verify
curl -X POST http://localhost:8000/api/debug/verify \
  -H "Content-Type: application/json" \
  -d '{
    "actual": {"status_code": 200, "body": {"data": null}},
    "spec": {
      "kind": "api",
      "target": "/api/users",
      "expect": {
        "status": 200,
        "body_rules": {"data": {"name": "expected"}}
      }
    }
  }'
