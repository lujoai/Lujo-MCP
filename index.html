Why Lujo-MCP

调试 AI 应用时，这些坑你一定踩过

传统监控能告诉你“挂没挂”，却很难告诉你“对不对”。

01

静默失败查不出

接口返回 200、没有异常日志，功能却不对：按钮没反应、字段缺失，靠人眼才能发现。

02

协同调试太慢

代码报错后，手动查日志、翻代码、拼提示词再丢给 AI，每轮要花 5 到 15 分钟。

03

前端网络盲区

请求体、响应体、耗时这些细节难以追踪，问题到底出在前端还是后端，定位很费劲。

Quick Start

一条命令装好

无需配置 Python 环境，npm 全局安装即用。

1 · 安装（npm 全局，开箱即用）
# 国内如遇 404 可指定官方源 npm install -g @lujoai/lujo-mcp --registry=https://registry.npmjs.org/
2 · 在 MCP 客户端中配置（Claude Desktop / Cursor / Trae 等）
{ "mcpServers": { "lujo-mcp": { "command": "lujo-mcp-server", "args": [] } } }
3 · 配置环境变量（stdio 模式必填）
LLM_PROVIDER=zhipu OPENAI_API_KEY=your-zhipu-or-openai-key LLM_MODEL=glm-4.7-flash

最小配置只需设置 LLM_PROVIDER 与 OPENAI_API_KEY；需要 PostgreSQL / Redis / Playwright 等能力时，参考仓库内的环境部署与功能启用指南逐项开启。
